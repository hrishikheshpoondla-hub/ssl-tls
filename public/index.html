Implementation of SSL/TLS in a Website

A practical demonstration of how HTTPS protects data in transit using real TLS encryption, digital certificates, and secure session management.

🌐 Browser
🔒 TLS Handshake
🖥️ Node.js Server :8443
🔑 bcrypt hash
🗄️ SQLite DB password_hash only
🔐

Real HTTPS/TLS

Server uses Node's built-in HTTPS module with a real TLS certificate — not simulated.

🔄

HTTP → HTTPS Redirect

Port 8080 (HTTP) automatically redirects all traffic to port 8443 (HTTPS).

🍪

Secure Cookies

Session cookies use HttpOnly, Secure, and SameSite=Strict.

🔑

Password Hashing

bcrypt (12 rounds) hashes passwords before storage. Plaintext is never saved.
